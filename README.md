# homebrew-tap

Fórmulas do Homebrew de [luiz-claudio-rj](https://github.com/luiz-claudio-rj).

## Converter para Mac

Converta vídeo, áudio e imagem com o botão direito no Finder. [Página do projeto](https://luiz-claudio-rj.github.io/finder-converter/)

```bash
brew install luiz-claudio-rj/tap/finder-converter
finder-converter setup
```

O ffmpeg e o webp são instalados junto, se ainda não estiverem no Mac.
