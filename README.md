# homebrew-tap

Pacotes do Homebrew de [luiz-claudio-rj](https://github.com/luiz-claudio-rj).

## Organizador para Mac

Organize arquivos em pastas por assunto com o botão direito no Finder. Você vê a proposta antes e pode desfazer. [Página do projeto](https://organizador.oluiz.dev/)

```bash
brew install luiz-claudio-rj/tap/finder-organizer
```

Um comando só: monta o app no seu Mac e instala a Ação Rápida no Finder. Não depende de nenhum outro programa.

## Converter para Mac

Converta vídeo, áudio e imagem com o botão direito no Finder. [Página do projeto](https://converter.oluiz.dev/)

```bash
brew install luiz-claudio-rj/tap/finder-converter
```

Um comando só: instala a Ação Rápida no Finder e o ffmpeg e o webp, se ainda não estiverem no Mac.

Quem instalou pela fórmula antiga (até a v1.2.1) troca assim:

```bash
brew uninstall --formula finder-converter
brew install luiz-claudio-rj/tap/finder-converter
```
